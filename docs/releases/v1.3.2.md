# dsh-knowledge v1.3.2 — Harness model selection

Open **Knowledge → your base → Settings**. Turn on **Caption photos later, only when idle** to choose a registered Harness model. The same catalog is available when selecting Harness for image captions during import. Models that declare image support can be selected directly. Text-only models appear disabled. Providers that omit capability metadata are marked **Image support unreported**. If a provider goes offline, the picker keeps its saved selection.

The one-button setup installs OvisOCR2, Qwen3 Embedding and Qwen3 Reranker. PDFs go through Markdown, chunking and embedding with both idle switches off. The photo pass adds descriptions of embedded PDF images. The chart pass uses local PP-Chart2Table to extract additional chart and table data. Neither pass processes Markdown articles.
