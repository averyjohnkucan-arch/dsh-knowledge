# Knowledge v1.3.1 — Clean uninstall

In Harness Web, open **Settings → Local Models → Uninstall and delete all KBs**. The same action appears at the bottom of a base’s **Settings** panel and applies to every local KB. Review the deletion details, then choose **Delete all local KBs and uninstall**. Knowledge uses the Harness package manager to unload and remove the package before erasing its data.

This action permanently erases every local base, uploaded file copy, generated Markdown file, search index, plugin setting and download in the plugin-managed storage. Linked source folders, exported archives and separately configured model caches stay on disk. If another profile in the same Harness home has Knowledge installed, remove its package first. In a personal AD reader the action appears in **Settings → Knowledge administration** and applies to the personal installation. The shared AD indexer is administered on its server.

Harness **Plugins → Remove** continues to support removing the package while keeping its data. Disabling Knowledge or updating it also keeps the library.

For a fresh install, open **Plugins → Add plugin**, paste `https://github.com/averyjohnkucan-arch/dsh-knowledge`, and choose **Install**. Enable Knowledge if prompted. Open **Knowledge** to see the empty base list. Create a base and open its settings to set up PDF OCR and local search.
