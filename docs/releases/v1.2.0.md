# Knowledge v1.2.0 — One-click PDF OCR and local search

In **Knowledge**, create or select a base. Open its **Settings** using the gear next to **Recall Test**. Click **Set up PDF OCR and local search**. You can close the panel while setup runs. Once it shows **Ready to import PDFs**, import a file using the usual **Upload file** action. Use **Recall Test** to search, then open a result’s indexed Markdown to see the passage in context.

## Fresh Harness installation

This release targets DeepSeek Harness 0.2.2-rc.4, Node.js 24.9 or newer, and the web profile. To install the prebuilt plugin in a fresh Linux profile using pnpm 11, run this command and then launch Harness. The command skips npm lifecycle scripts for this install. The release includes the compiled plugin and the search runtime ships its CPU binaries.

```sh
pnpm_config_ignore_scripts=true dsh plugin --profile web add https://github.com/averyjohnkucan-arch/dsh-knowledge/releases/download/v1.2.0/dsh-knowledge-1.2.0.tgz
dsh --profile web
```

The setup button installs a private Python interpreter, the OCR model and visual encoder, the PDF reader, inference runtime, tokenizers, Qwen3 Embedding 0.6B and Qwen3 Reranker 0.6B. It verifies the pinned public model files, checks embedding and reranking results, and reads a test image with OCR. Allow internet access during setup. Document recognition and search run locally after installation. No separate model account, API key, Python environment or model registration is required.

## Hardware and storage

| Linux x86-64 OCR backend | Selection | Approximate installed size including both Qwen search models |
| --- | --- | --- |
| OvisOCR2 BF16, vLLM | First NVIDIA GPU has compute capability 8.0+, at least 22,000 MiB VRAM, driver 580+, and a host C compiler is available | 12.5 GB before inference caches |
| OvisOCR2 Q4_K_M and Q8_0 projector, llama.cpp | Other Linux x86-64 hosts use the compact runtime on supported Vulkan hardware or CPU | 3.4 GB before caches |

Setup needs additional temporary disk space for downloaded wheels, unpacking and compilation. An eligible Intel search accelerator can also download its own embedding runtime assets. Runtime files live in derived directories under `$DSH_HOME/storages/knowledge-markdown-v1`, with `~/.dsh` as the default Harness home. Bases in the same Harness home reuse those files. Existing macOS, Windows and other-architecture installations can continue using the plugin’s other document processors.

## Imports, recovery and handoff

- Native prose and simple ruled tables can be read directly. The pipeline rasterizes pages that need OCR and preserves page order in the Markdown. Scans and supported image imports use OvisOCR2. Recognition warnings identify pages for review. An incomplete document fails before partial text can enter the index.
- Setup applies the selected models only to the requesting base, keeps its chunk settings, and enables indexed Markdown. Existing bases with incompatible embeddings use the plugin’s normal rebuild flow. For PDFs already indexed, use **Reparse source** to regenerate the Markdown from the original file.
- Reopening Settings shows the running stage or the failure. Use **Retry PDF OCR and search setup** after resolving a problem such as insufficient disk space. A Harness restart resumes a pending install and reuses verified downloads. The OCR worker stays warm between imports and releases the model after a minute idle.
- The host entry points are `src/host/local-search.js` and `src/host/ocr.js`. The versioned worker, OCR prompt, dependency locks and model manifests ship in `src/runtime/ocr/`. The Knowledge service routes extracted Markdown through `src/knowledge/document-processing.ts`. Run `pnpm test`, `pnpm run typecheck` and `pnpm run build` when changing these interfaces.

To repeat the end-to-end check on a running local Harness, provide a small PDF and a phrase visible in it. The smoke test creates a temporary base, runs setup, checks the saved Markdown, 1,024-dimensional vectors and search result, then removes that base.

```sh
node scripts/smoke-document-setup.mjs http://127.0.0.1:3000 sample.pdf "expected phrase"
```
