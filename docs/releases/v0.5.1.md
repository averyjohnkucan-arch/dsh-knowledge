# dsh-knowledge v0.5.1 — Search exclusions and DSH directory fixes

Version 0.5.1 adds document exclusions and restores local-model and MinerU directory
buttons in DSH 0.2. This helps exclude bibliographies, contents pages, and processing
logs from knowledge retrieval.

## Search exclusions (#39)

- HTTP `/knowledge/search` filters accept `excludeDocIds` and `titleExcludes`.
  `knowledge_search` exposes the same names as top-level parameters; client types match.
- Document IDs match exactly. Title filters trim whitespace and use case-insensitive
  substring matching rather than regular expressions. Any matching nonempty term excludes a document.
- Exclusions win over inclusions and apply before lexical/vector candidate limits,
  fusion, MMR, and reranking, so excluded documents cannot consume the Top K quota.
- ID sets larger than 500 work. Empty lists and unknown IDs leave results unchanged.
  Malformed HTTP fields return `400 invalid_request`.

```json
{
  "query": "document handling procedure",
  "topK": 5,
  "filter": {
    "titleExcludes": ["Bibliography", "Table of contents", "Processing log"]
  }
}
```

Omit `baseId` to search all bases; provide a valid ID to target a particular base.

## Directory buttons (#42)

- Restore local-model cache Browse/Open and MinerU directory selection on DSH 0.2,
  fixing `pickDirectory/openPath is not a function`.
- Support new and older host interfaces, checking capabilities per method. Cancellation
  retains the previous path; missing capabilities preserve manual entry; errors stay visible.
- Resolve absolute cache paths and expand `~` on the backend before opening. Empty input
  uses the effective cache directory. Explicit opening may create a missing directory.
- Opening a directory does not save settings, migrate models, or start downloads.

## Upgrade and upstream validation record

Upgrading from 0.5.0 requires no database migration, reindexing, document relocation,
or new dependencies. Exclusions are opt-in per request; existing inclusion filters work.

The upstream fixes passed 529 local regression tests, typecheck, build, retrieval
benchmarks, and package checks. Main recall/evidence benchmark scores remained 100%.
Directory regressions cover old/new contracts, actual callbacks, and real HTTP requests.
Native DSH 0.2 dialog/file-manager acceptance remains separate. These are historical
upstream results, not a certification of later fork changes.

Managed MinerU remains experimental. This historical release retained two temporary
high-severity sharp exceptions under `@huggingface/transformers`, expiring **2026-10-14**.
Those exceptions were subsequently removed in 0.5.2; they are not a current waiver.
