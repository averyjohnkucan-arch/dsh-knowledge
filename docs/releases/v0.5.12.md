# v0.5.12 — saved indexed Markdown and folder Sync

A base's Advanced settings now include **Keep internal Markdown**, off by default. Enabling it affects future imports, reindexing and synchronization, without automatically rewriting prior documents. Each successful indexing generation can retain the exact extracted text as an immutable internal `.md` revision, separate from the original source and structured parsing artifacts.

Citation links open a script-free escaped viewer and highlight ranges verified against that saved text, with source line numbers. Previously cited revisions remain available after reindexing while the document exists. If a transformed passage cannot be mapped reliably, the viewer labels it and shows its indexed excerpt rather than highlighting an invented range. Existing PDF page/block references and original-source downloads remain available. This is indexed source text, not regenerated Markdown formatting or a replacement for original-file backups.

Folder context menus have **Sync** as their fourth action. It starts a background job and reports progress and failures without blocking Recall. The sync checks source identity plus relevant extraction, chunking, embedding and Markdown-retention settings. Changed work is rebuilt using current settings; unchanged indexed text reuses vectors. Legacy documents without settings fingerprints receive current settings on explicit Sync. Missing retained Markdown is repaired by a later sync. Repeated clicks share the active job; overlapping folder jobs are rejected.

Removing an original file and syncing removes its KB record and retained Markdown revisions. Deleting indexed data or internal Markdown never deletes original source files. An existing synced source folder can be imported again by automatic synchronization. Saving the retention setting off stops future generation copies; older cited revisions remain until the document or base is removed.

All host changes stay within the Cordis Knowledge plugin, use its service lifecycle and preserve the original source files. Reload the plugin to activate them. Also contains worker broken-pipe error handling and all 0.5.11 Recall/accelerator/failure-reporting fixes.
