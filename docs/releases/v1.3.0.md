# Knowledge v1.3.0 — Active Directory and Windows shares

Knowledge now supports a private Linux indexer, an HTTPS reader for on-premises AD, and signed-in search from a personal DeepSeek Harness. Assign separate AD security groups to document reading, settings, synchronization, model installation and group-policy administration. Settings administrators can change global defaults or a visible base from Knowledge. The Windows file server still decides which folders and files they can read.

The reader checks source permissions before reranking and fetches more candidates when restricted hits fill the initial window. It verifies current source bytes before exposing saved Markdown, citations or downloads. Personal Harness chat uses the same authenticated reader.

Install the release asset and follow the [deployment guide](https://github.com/averyjohnkucan-arch/dsh-knowledge/blob/v1.3.0/docs/active-directory.md) for the two configuration files, Linux prerequisites, CA setup and group assignments. Existing single-user installations keep their current behavior until a deployment mode is configured.

~~~sh
pnpm_config_ignore_scripts=true dsh plugin --profile web add https://github.com/averyjohnkucan-arch/dsh-knowledge/releases/download/v1.3.0/dsh-knowledge-1.3.0.tgz
~~~
