# 0.5.4

This release adds an optional accelerated Qwen3 Embedding 0.6B FP16 profile and
reduces redundant ingestion work without modifying DeepSeek Harness.

## Install and upgrade

Paste https://github.com/averyjohnkucan-arch/dsh-knowledge into the DSH plugin
installer, restart the web service and refresh. The GitHub default branch ships
compiled assets. Download/validate the accelerated profile in Settings → Local
Models, then select it in the base settings. Python packages and model weights
are installed into the plugin cache, not system Python. Hardware drivers remain
an OS prerequisite. Windows bootstrap paths are included; hardware acceptance
was performed on Linux only.

Changing between recognized Qwen exports starts vector-only migration from
existing chunks. Lexical retrieval stays available. Different exports and vector
format revisions have separate identities and are never mixed. Existing tiny
chunks require an explicit **Rechunk saved parsing result** to adopt paragraph
packing or semantic settings. This preserves the parsed artifact and does not
repeat OCR. **Re-vectorize all** only replaces vectors and reports progress.

## Scheduling and quality

CPU/NPU continue indexing while GPU workers help when available. Device queues
are bounded, CUDA batches similar lengths, and two CUDA workers are used when
VRAM permits. Foreground DSH inference withdraws GPU workers through the public
LLM hook. Detected external demand stops new GPU jobs immediately and allows at
most ten seconds for the current job. Unfinished requests fall back to CPU.
Query embedding is restricted to CPU/NPU regardless of GPU availability.

The NPU graph on the tested Intel driver supports short candidates up to 256
tokens; longer texts use CPU/CUDA without truncating Qwen's 32K model context.
Semantic candidate packing defaults to 128 tokens; adjacent similar candidates
merge within the configured final chunk size and never across headings or code
fences. Their length-weighted vectors are reused rather than recomputed.

See [the benchmark report](../embedding-performance.md) for tested rates,
quantization comparisons, cross-device checks and acceptance limits.
