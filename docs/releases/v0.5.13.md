# v0.5.13 — Sync reconciles Markdown retention

Folder **Sync** now applies the current **Keep internal Markdown** setting to every file in the selected folder and its descendants. When retention is off, it deletes all internal Markdown revisions, including older copies left by previous reindexing. Their saved-Markdown citation URLs will no longer resolve. Original sources, stored index text, chunks and vectors remain intact.

Saving the setting alone still does not rewrite existing documents. A retention-only cleanup skips parsing and embedding; other changed processing settings or source contents continue to rebuild normally. Cleanup errors are reported as per-file failures and can be retried with Sync. Turning retention back on allows future generations and Sync to save new copies.

Implemented entirely inside the existing Cordis Knowledge plugin. Reload the plugin after active indexing finishes to activate the backend change.
