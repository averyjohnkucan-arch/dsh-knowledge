# 0.5.7 — yield background GPU memory before foreground model loading

Knowledge optionally registers a foreground resource guard with Model Scheduler 0.1.4. The scheduler invokes it before an image renderer or chat model loads, including automatic chat restoration after rendering. The guard prevents new GPU embedding work and waits for owned GPU workers to exit; CPU and NPU embedding lanes remain available. Standalone installs retain the public LLM streaming hook.

Worker shutdown now waits for process exit for up to ten seconds, including workers already killed by a canceled request. This avoids treating a cleared process handle as proof that its GPU memory has been released. No Harness core changes or external process termination are involved.

Validated with scheduler ordering, image-to-chat restoration, failed guard, shutdown and cancellation tests; Knowledge guard registration/disposal and real owned-worker exit tests.
