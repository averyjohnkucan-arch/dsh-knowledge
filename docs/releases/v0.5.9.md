# 0.5.9 — bounded vector search outside the Harness event loop

File-backed vector retrieval now streams embeddings in a readonly worker and retains only top K, instead of loading every embedding and passage into a main-thread cache and sorting the whole corpus. Searches have a three-second vector-lane budget; a timed-out lane reports degradation and allows lexical results. Query embedding has a separate 2.5-second waiting budget so bulk indexing cannot pin Recall Test indefinitely. The Recall panel exposes keyword fallback instead of hiding it.

This is still exact brute-force retrieval, not an ANN index. Large corpora can exceed the scan budget and use keyword fallback. No claim is made that semantic search over millions of vectors now completes within three seconds. A separate ANN index would be needed to remove that scaling limit.

Real 17 GB index probe: the vector worker stopped after 3,006 ms while 289 ten-millisecond event-loop ticks were serviced. File-backed tests cover ranking, scope/model filtering, updated vectors, deadline errors, and event-loop responsiveness. All changes are plugin-contained.
